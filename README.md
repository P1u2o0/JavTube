## 为什么是它

- **只为本地库而生**：不联网也能浏览、筛选、播放。除刮削外全程离线，数据只存在本机 `data` 目录，不上传任何内容。
- **双播放内核**：默认 mpv（与 PotPlayer 同源），另备 Chromium 内核。少数时间戳不规范的 MP4 在浏览器内核里恒定丢帧、卡顿，mpv 能正常播。
- **按你的方式找片**：标签分组多选、筛选夹一键切回、观看进度一眼可见、演员墙与热度排行。
- **清理不用靠手翻**：目录查重按番号找「同目录出现两次以上」的视频，逐条由你决定去留。

## 功能

### 刮削

集成 JAVBUS / JAVDB 两个源，一次补齐番号、标题、导演、片商、系列、类别、女优（含头像）、评分、想看/看过人数与预览图；不想抓的字段可以在设置里关闭。

### 片库与筛选

- 海报墙浏览，标签按**主题 / 角色 / 服装 / 体型 / 行为 / 玩法 / 类别**分组，可多选叠加
- 排序方式、每行数量、每页数量都可调
- 批量操作：删除 / 收藏 / 刮削 / 加标签
- **筛选夹**：把常用的「标签组合 + 搜索词 + 排序」存成命名条目（如「巨乳 + 中文字幕」），下次一键切回，同名可覆盖
- **观看进度**：看过但没看完的影片，海报下沿有一条进度条

### 影片详情

番号、日期、时长、评分、想看/看过、导演、片商、类别、演员，配大幅预览图与缩略画廊；可直接进入播放页或用外部播放器打开。

### 播放

两种内核，设置里一键切换：

| 内核 | 说明 |
|---|---|
| **兼容模式（默认，mpv）** | 与 PotPlayer 同源。码流用了 B 帧但 MP4 缺 `ctts` 盒的影片，浏览器内核会恒定丢约 20% 帧（看着一卡一卡），mpv 按码流顺序还原时间轴，正常播放；同时支持 AVI / TS / FLV 等封装与 10bit HEVC / VC-1 / MPEG-2 等编码 |
| **标准模式（Chromium）** | 用浏览器内置媒体栈，启动更快，无额外体积 |

两种模式都支持键盘控制、倍速、进度记忆；进入全屏是**瞬时切换**（没有窗口缩放动画），全屏时控件条完整可见。

**自动属性标签**：从文件名识别 **无码破解**（`-U` / `-破解`）、**中文字幕**（`-C`）、**4K**（文件名标注或读取真实分辨率）；`-UC` 即无码破解 + 中文字幕。

播放窗口下方展示全部参演女优（多人共演全部平铺，可点进个人页），右侧按观看口味推荐相关影片，推荐项同样带属性标签。影片编码确实异常时会给出提示，并可一键改用外部播放器。

### 演员

- **头像墙**：按作品数量排序
- **热度排行**：按热度指数降序，每行显示名次、头像与想看人数最高的 3 部影片，火焰图标按名次分 7 档配色

### 喜欢与观看记录

喜欢页存放收藏；观看记录支持按**播放时间**或**播放次数**排序（点同一项切换正序/倒序），卡片上带播放次数与观看进度。

### 维护工具

**目录查重**（设置 → 辅助设置）
- 选一个目录，或直接粘贴 NAS 路径；只读递归扫描视频
- 按番号分组，**只列出「同一目录里出现两次以上同番号」的视频**（跨子目录也算），组内按体积从大到小排，第一行标「体积最大」
- 每条只有两个动作：**在资源管理器定位**，或**移入回收站**（系统回收站，可还原）
- 不做自动删除；库内正在使用的那个文件一律拒绝处置

**失效图片修复**
- 扫描全库封面与预览图，发现空文件 / 打不开 / 站点拦截页时重新刮削补齐
- 可设为启动时自动检查

## 快捷键

在「设置 → 播放设置」里可改键位。

| 按键 | 作用 | 按键 | 作用 |
|---|---|---|---|
| `Space` | 播放 / 暂停 | `F` | 全屏 / 退出全屏 |
| `←` / `→` | 后退 / 前进 5 秒 | `M` | 静音 |
| `↑` / `↓` | 音量加 / 减 | 长按 `→` | 2 倍速快进（松手恢复） |

## 下载与安装

1. 到 [Releases](https://github.com/P1u2o0/JavTube/releases/latest) 下载 `JavTube-v*-win-x64.zip`
2. 解压到任意目录，双击 `JavTube.exe`（绿色版，免安装）
3. 首次启动后：设置里填 JAVDB Cookie 与代理（若要抓评分/想看人数），然后「导入」影片目录

**升级**：新版本覆盖到同一目录即可，`data` 目录（数据库、图片）不会被改动；建议升级前在设置里备份一次数据库。

**数据位置**：`JavTube.exe` 同级的 `data/` —— `app.db`（影片与标签）、`images/`（封面 / 预览图 / 头像）、`tag-categories.json`（标签分组）。

## 常见问题

**刮不到评分和想看人数？**
评分与人数只来自 JAVDB，需要 Cookie，并在设置里配置代理；Cookie 过期会静默失败，重新粘贴即可。

**播放卡顿 / 画面一卡一卡？**
保持「兼容模式（mpv）」；个别文件确实异常时，播放页会提示并可一键改用外部播放器。

**海报缺失？**
影片已入库但没刮到封面时会显示占位图。设置 → 辅助设置 → 「检查并修复失效图片」可以批量补齐。

**查重会删我的文件吗？**
不会。扫描全程只读，处置只有一个动作：把文件移入**系统回收站**（可还原），而且必须逐条确认。

## 本地开发
