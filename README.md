# JavTube

> 一款的本地jav影片管理软件 —— 刮削、整理、筛选，你的私人片库一站搞定。

JavTube 基于 Electron + Vue 3 构建，所有数据（影片信息、标签、收藏、观看记录）仅保存在本机 `data` 目录中，**不上传任何内容**。无需注册，除刮削外均无需联网。

## 页面与功能

### 🏠 首页

启动即见的三块内容，数据由主进程一次聚合返回：

- **封面流轮播**：中心大海报 + 左右各两张半幅，共 5 个可见槽位；左右按钮首尾循环，自动轮播到尽头自动反向；点中心海报进详情，点两侧海报把它移到中心；指示点可直接跳转
- **类别快捷入口**：取全库出现频率最高的 5 个标签生成 16:9 横向卡片，每张卡片的背景海报互不相同（主进程三级去重）
- **近期上新**：4 列 × 2 行共 8 部，优先挑选与「最近观看画像」（最近 20 部的标签 / 系列 / 女优）无交集的作品，帮你翻出被冷落的库存

轮播结果在本次运行内保持稳定，重启应用后重新随机。

### 🎬 片库

- **标签筛选**：9 个自定义类别分组，组内标签按「含该标签的影片数」降序排列；多个标签之间为 **AND 叠加**，越点越精准；「全部」一键清空
- **搜索**：番号 / 片名 / 标签三字段模糊匹配，回车即搜
- **排序**：添加日期 / 发行日期 / 想看人数 / 看过人数 / 评分 / 随机排序，点击当前项切换正倒序
- **浏览密度**：每行 3–8 列、每页 10–200 条，均可在设置中调整
- **多选批量操作**：全选 / 反选 / 批量删除 / 全部收藏 / 取消收藏 / **批量刮削**（结果在顶栏铃铛面板实时可见）
- **影片卡片**：悬停出现播放按钮（已关联视频文件时）、右上角心形收藏、播放次数角标

### 📄 影片详情

- **海报区**：按封面原始比例计算尺寸并自适应窗口，加载失败显示占位
- **播放**：已关联视频文件时，悬停海报出现播放按钮；播放会记录观看时间并累加观看次数
- **预览图画廊**：封面与预览图组成横向图条，首张带「海报」角标，悬停后**滚轮即可横向滚动**（到两端不劫持页面滚动）
- **灯箱查看器**：点击任意图片全屏查看，左右按钮或 `←` / `→` 键切换，`Esc` 关闭，滚轮缩放 0.5–5 倍，带页码指示
- **信息区**：番号（一键复制）· 发行日期 · 时长（无刮削值时自动解析本地 MP4 补齐）· 评分（五星按比例填充）· 想看 / 看过人数 · 导演 / 片商 / 系列 / 类别 / 演员 —— 全部可点击，直接跳到对应筛选结果
- **操作**：喜欢 / 重新刮削 / 编辑元数据 / 删除（二次确认）

### 👤 演员影片页

在详情页点击演员名字即可进入该演员的作品列表：

- 顶部为演员区：头像 + 性别标识（无头像时按性别显示默认剪影）+ 资料摘要（身高 / 三围 / 罩杯 / 生日 / 出道日期）+「N 部作品」
- 下方是**与片库完全同款**的标签筛选栏、排序下拉、影片网格与分页，操作习惯无需重新适应
- 作品按演员名匹配（含多演员影片），并取演员资料一并展示

### ❤️ 喜欢 / 🕘 观看记录

- **喜欢**：独立页面回看收藏，同样支持标签筛选与批量操作；取消收藏后影片立即离开列表
- **观看记录**：按最近播放时间倒序，卡片右上角显示观看次数角标

## ⚙️ 刮削引擎

### 数据源与策略

| 来源 | 说明 |
|---|---|
| JAVBUS | 详情 + 女优头像 |
| JAVDB | 详情 + **评分 / 想看 / 看过** |
| 自动 | 有码影片 JAVBUS 优先、JAVDB 兜底补齐评分统计；欧美影片仅 JAVDB |

- 抓取字段：番号、片名、封面、演员（含头像与性别）、发行日期、标签、导演、片商、系列、时长、预览图，以及 JAVDB 的评分与热度
- JAVBUS 命中后，若开启了评分或预览图下载，会**静默补抓一次 JAVDB**，用非空字段填补缺口
- 繁体标签自动转换为简体
- **标签映射在刮削那一刻自动应用**（见下文标签系统）

### 网络与反爬

- 网络层走**系统 curl**（刻意不走 Chromium / Node 的请求栈，以通过部分站点的 TLS 指纹检测）
- 同域名请求限速 400ms，避免触发封禁
- **代理**：可开关，设置后即时生效；下载图片时按域名决定「代理优先」还是「直连优先」，两种都尝试
- **JAVDB Cookie**：支持粘贴 Cookie 以通过 Cloudflare 盾
- IP 封禁、版权限制、Cloudflare 盾等拦截会被识别并转为**可操作的中文提示**，而不是甩一段原始报错

### 图片全量本地化

封面存 `covers/`、预览图存 `covers/previews/`、女优头像存 `covers/actress/`，全部落在本机数据目录。预览图下载可开关，数量 0–50 可调（0 = 全部）；未开启时不会把外链写进数据库，保证离线也能完整显示。

### 任务面板

顶栏铃铛实时显示刮削任务数，面板分「正在刮削 / 待刮削 / 刮削失败」三组，失败可一键清除。

## 🏷️ 标签系统与标签映射

- **9 个类别槽位**：类别名与标签内容全部可自定义（默认 C1–C9），按中文逗号分隔录入
- **AND 组合筛选**：不同类别、同类别多标签同时生效
- **标签映射**：`原标签 → 新标签` 规则表，刮削时自动套用；新标签留空即**删除**该标签
- **应用到现有影片**（v1.3.0 新增）：映射规则默认只对之后的刮削生效，这个按钮把当前规则补算到整库 —— 先**干跑预览**（列出每部影片会被删除 / 替换的标签），确认后才一次性写入，全程事务保护；一条都不匹配时只提示、不弹窗

## 📥 导入

「扫描目录」递归查找视频文件，自动从文件名提取番号（可手动修正），勾选后批量入库：

- 按**番号去重**，重复导入不会产生重复记录
- 已有记录的视频路径失效时，重新扫描会**自动回填**新路径

---

## 💾 数据安全

- **备份**：先把内存数据库完整落盘，再复制导出，确保拿到的是最新状态
- **恢复**：从备份文件还原（还原后重启生效）
- **清空**：危险操作双重确认
- **原子落盘**：写入临时文件 → 旧库改名 `.bak` → 新库就位，双 rename 保证任意时刻崩溃都留有完整旧库；另有 10 秒定时落盘 + 退出时强制保存

## 🎨 设计与工程细节

- **设计令牌体系**：暖纸白底 + 墨黑主色 + 品牌红点缀；颜色、五级圆角、三级阴影、四档缓动曲线、字号阶梯、间距全部令牌化（`src/styles/global.css`），无硬编码色值
- **SVG 图标体系**：33 枚自绘线性图标，统一 24×24 viewBox 与线宽，跟随 `currentColor`
- **字体**：Inter 四档字重本地托管 + 中文字体回退链，无外网依赖
- **动效**：错峰入场、iOS 曲线抽屉、`prefers-reduced-motion` 全量降级
- **`javtube-cover://` 自定义协议**：解决 Electron CSP 下本地图片无法显示的问题，带扩展名白名单、根目录限定与文件存在性三重校验
- **零依赖 MP4 时长解析**：主进程直接遍历 ISO-BMFF box 读取 `mvhd`，不引入 ffmpeg
- **安全模型**：`contextIsolation: true` + `nodeIntegration: false`，渲染层仅能通过 `window.api` 调用主进程；40 个 IPC 通道名集中常量化管理

## 🛠️ 技术栈

| 层 | 技术 |
|---|---|
| 桌面框架 | Electron 30 |
| 前端框架 | Vue 3（`<script setup>`）+ Vite 5 |
| UI 组件 | Element Plus（深度主题定制） |
| 状态管理 | Pinia + Vue Router（Hash 模式） |
| 数据库 | sql.js（SQLite WASM，纯本地文件，免原生编译） |
| 元数据刮削 | 主进程 + 系统 curl 抓取，HTML 解析（JAVBUS / JAVDB） |
| 打包分发 | electron-builder + 自研绿色版打包脚本 |

**架构**：主进程（窗口 / 刮削 / 数据库 / 自定义协议）→ 预加载脚本（`contextBridge` 暴露 `window.api`）→ 渲染进程（Vue 页面）。所有 IPC 统一返回 `{ ok, data, error }` 结构。

## 📦 下载使用

前往 [**Releases**](https://github.com/P1u2o0/JavTube/releases) 下载 Windows x64 绿色版（免安装，解压即用）。

**覆盖即更新**：

1. 关闭正在运行的 JavTube；
2. 用新版压缩包内的 `JavTube.exe` 与 `resources` 覆盖旧版目录；
3. **保留 `data` 文件夹**（影片库、标签、设置都在里面）；
4. 重新打开即完成升级，旧数据库自动补齐新字段，无需手动迁移。

## 🚀 本地开发

```bash
# 1. 安装依赖
npm install

# 2. 开发模式（Vite 热更新 + Electron）
npm run dev

# 3. 代码检查
npm run check:undefined

# 4. 打包 Windows 绿色版 zip（输出到 release/）
npm run release
```

│   │   ├── video-meta.js       # MP4 时长解析
│   │   ├── home.js             # 首页数据聚合（轮播 / 类别 / 上新）
│   │   └── db/                 # 影片 / 女优 / 网址 / 设置 / 建表与迁移
│   └── preload/
│       └── index.js            # contextBridge 暴露 window.api
├── src/
│   ├── views/                  # 首页 / 片库 / 详情 / 喜欢 / 观看记录 / 演员影片页
│   ├── components/             # 顶栏 / 卡片 / 网格 / 标签筛选 / 排序 / 状态栏 / 设置 / 导入
│   ├── store/                  # Pinia 状态：影片 / 刮削 等
│   ├── composables/            # 列表加载复用逻辑
│   ├── router/  utils/  styles/
├── scripts/
│   └── build-portable.js       # 绿色版打包（含 asar 瘦身 / 图标版本信息写入 / 自检）
